# Interactive Bloom System

这是一个基于 HTML5 Canvas 的互动开花网页，适合复刻“小红书 Vibe Coding / 代码驱动开花动画”一类视觉案例。

## 已实现功能

- 点击生成花朵
- 拖动鼠标沿轨迹连续开花
- 花朵分阶段生长：光点 → 茎叶 → 花苞 → 内层花瓣 → 外层花瓣 → 花心与花粉粒子
- 花朵开完后保留轻微呼吸和摆动
- 背景漂浮粒子与柔和舞台光晕
- R 清空画面
- S 慢动作模式
- H 显示 / 隐藏说明
- 自动开花模式

## 使用方式

直接打开 `interactive-bloom/index.html` 即可运行。

如果要部署到 GitHub Pages，可以把这个目录作为静态页面路径使用。
