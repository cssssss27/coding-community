# Interactive Bloom Camera System

这是摄像头交互版本的互动开花网页，适合复刻“小红书 Vibe Coding / 代码驱动开花动画”一类视觉案例。

## 当前交互逻辑

- 摄像头识别手部。
- 手经过画面时只显示追踪光标，不开花。
- 只有从张开 / 移动状态变成攥拳状态时，才在手掌中心触发一次开花。
- 攥拳保持不松开时不会连续开花，内部有 850ms 冷却和状态判断。
- R 清空画面。
- S 慢动作模式。
- H 显示 / 隐藏说明。
- M 开启鼠标调试模式，方便没有摄像头时临时测试。

## 使用方式

直接打开 `interactive-bloom/index.html`，点击“启动摄像头”，允许浏览器访问摄像头。

推荐通过 HTTPS 或 localhost 访问。若直接双击本地文件时摄像头权限异常，请在仓库根目录使用本地服务器，例如：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080/interactive-bloom/
```

如果只下载了 `interactive-bloom` 文件夹并在该文件夹内启动本地服务器，则访问：

```text
http://localhost:8080/
```

## 技术说明

本版本使用 HTML5 Canvas 绘制开花动画，使用 MediaPipe Hands 识别手部关键点。页面需要浏览器摄像头权限，且首次启动需要联网加载手势识别库。

判断逻辑不是“手经过就开花”，而是：

1. 读取手掌中心位置。
2. 判断指尖是否向掌心收拢。
3. 当状态从“非攥拳”切换为“攥拳”时，在手掌中心触发一次开花。
4. 攥拳保持期间不连续触发，松开后再次攥拳才会生成下一朵。
