# Interactive Bloom Layered Camera System

这是摄像头交互版本的互动开花网页，适合复刻“小红书 Vibe Coding / 代码驱动开花动画”一类视觉案例。

## 当前交互逻辑

- 摄像头识别手部。
- 手经过画面时只显示追踪光标，不开花。
- 只有从张开 / 移动状态变成攥拳状态时，才在手掌中心触发一次开花。
- 攥拳保持不松开时不会连续开花，内部有 850ms 冷却和状态判断。
- R 清空画面。
- S 慢动作模式。
- H 显示 / 隐藏说明。
- M 开启鼠标调试模式，方便没有摄像头时临时测试。
- W 显示 / 隐藏风场可视化。

## 四层开花系统

### 第一层：制作花瓣 `PetalShape`

负责单片花瓣本身的形态，包括：

- 贝塞尔曲线轮廓；
- 花瓣宽度、长度、透明度；
- 花瓣脉络线；
- 花瓣边缘卷曲；
- 光照、高光和渐变色。

### 第二层：制作花瓣排列结构 `PetalLayout`

负责花瓣如何组成一朵花，包括：

- 内层花瓣数量；
- 外层花瓣数量；
- 圆周角度分布；
- 内外层错位角度；
- 每一片花瓣的展开延迟。

### 第三层：模拟开花 `BloomSimulation`

负责完整生命周期：

1. 地面光点出现；
2. 茎从底部生长；
3. 叶片展开；
4. 花苞膨胀；
5. 内层花瓣打开；
6. 外层花瓣打开；
7. 花心发光；
8. 花粉粒子扩散；
9. 开花后进入呼吸与轻微摆动。

### 第四层：风场 `WindField`

负责统一的风力与风向，不只是视觉线条，会真实影响：

- 茎的弯曲；
- 叶片摆动；
- 花瓣张开后的微摆；
- 花粉粒子的漂移方向。

按 `W` 可以显示 / 隐藏风场可视化。

## 使用方式

直接打开 `interactive-bloom/index.html`，点击“启动摄像头”，允许浏览器访问摄像头。

推荐通过 HTTPS 或 localhost 访问。若直接双击本地文件时摄像头权限异常，请在仓库根目录使用本地服务器，例如：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080/interactive-bloom/
```

如果只下载了 `interactive-bloom` 文件夹并在该文件夹内启动本地服务器，则访问：

```text
http://localhost:8080/
```

## 技术说明

本版本使用 HTML5 Canvas 绘制开花动画，使用 MediaPipe Hands 识别手部关键点。页面需要浏览器摄像头权限，且首次启动需要联网加载手势识别库。

攥拳判断逻辑：

1. 读取手掌中心位置；
2. 判断指尖是否向掌心收拢；
3. 当状态从“非攥拳”切换为“攥拳”时，在手掌中心触发一次开花；
4. 攥拳保持期间不连续触发，松开后再次攥拳才会生成下一朵。
